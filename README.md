# Weather Data Analyzer (CLI)

A simple command-line Python application for loading, cleaning, analyzing, and reporting daily weather data from a CSV file.  
This project is designed as a lightweight data-processing exercise with clear separation of concerns and small, testable functions.

---

## 📌 Features

- Load weather data from a CSV file
- Validate and clean raw input data
- Filter records by city and date
- Calculate basic statistics:
  - Average temperature
  - Minimum temperature
  - Maximum temperature
- Generate a simple summary report in the terminal
